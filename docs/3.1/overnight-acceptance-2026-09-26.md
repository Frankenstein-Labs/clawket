## Findings and release decision

**Release decision: HOLD.** The five backends have substantially broader real-device/development coverage, with the fixes and passing rechecks documented below. That is not an unconditional production sign-off.

1. **Connection stability remains the first blocker.** Multiple Mac sockets and an independent Android socket repeatedly lost incoming frames at half-hour boundaries; a cloud-origin socket stayed healthy for about 100 minutes. Candidate recovery restores service, but the exact proxy/upstream/edge cause is not proven. Do not blame a specific vendor, promise uninterrupted Preview service, or consider a larger heartbeat budget a fix. Next isolate a usable independent network route, reproduce with the same candidate, then validate foreground/background and in-flight recovery across several boundaries with native message counts.
2. **Freeze and verify the release candidate.** This working tree includes pre-existing concurrent work. Focused serial gates are green, but no fresh whole-candidate required CI or Production-snapshot compatibility matrix has run for the final combined tree. Run those against a fixed commit before any authorized rollout. Earlier v1 replay passes only gate the Preview deployments recorded below.
3. **Keep native and distribution boundaries explicit.** Claude original-session continuation passes after owner release; an idle native owner remains protected. CLI reverse continuation passes, while reverse Desktop GUI reopening is still unverified. Codex native Stop did not kill an already-running shell command in the observed case. Physical iPhone, signed-store upgrade/entitlement and complete voice interruption coverage remain outside tonight's evidence.

Suggested eventual rollout dependency remains Bridge → isolated backend services → client, with compatibility/health checks between stages and the owner's separately scoped release authorization. This report has not prepared distribution packages, published packages, changed Production, or submitted either store.

Remaining lower-priority findings must also remain visible: a cancelled native tool can still read Failed and AskUserQuestion can expose its raw tool name in tool history; one development session panel stayed offscreen until cold launch and did not reproduce afterward; burst ADB Latin-key injection lost characters even though native Chinese IME and system paste passed.
